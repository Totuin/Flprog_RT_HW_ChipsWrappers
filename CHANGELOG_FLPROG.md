# История изменений FLProg_RT_HW_ChipsWrappers

## 1.0.1 — 10.11.2026

Небольшой совместимый выпуск на базе предоставленного исходного архива `1.0.0`.

### Исправления кода

1. **DS18x2x:** через `using AbstractTaskDevice::pool` раскрыта унаследованная перегрузка без параметров; исправлено предупреждение `-Woverloaded-virtual`, без переименования `pool(uint16_t)`.
2. **TCA9555:** при изменении выходного значения снова устанавливается флаг записи регистров. Раньше после первого цикла дальнейшие изменения могли остаться только в кэше. Скорость по умолчанию уменьшена с `800000` до `400000` Гц согласно спецификации TI.
3. **TM1637:** заменён `toCharArray(..., copyLen)`, который терял последний видимый символ, на копирование ровно `copyLen` символов с сохранением завершающего `\0`.
4. **TCA8418:** счётчик нажатых кнопок теперь не меняется при повторном событии; отброшены недопустимые коды и чтение за границами матрицы. Чтение FIFO за один вызов ограничено 10 событиями, чтобы не зависнуть при ошибке I2C.
5. **ADS1115:** для `getChanelADSValue()` добавлена защита от недопустимого индекса 8 и более (возвращается 0).
6. **Примеры:** исправлены имена класса и заголовка PCF8574, имя класса PCF8575, обход всей матрицы 8×10 в TCA8418.
7. **Публичные заголовки:** пути в `#include` с обратными слэшами заменены на переносимые прямые слэши; Windows поддерживает их также.

### Документация

- Добавлены русские Doxygen-комментарии к **28 объявлениям классов и 111 реализациям методов**.
- Уточнены пояснения к сбросу/восстановлению заданий, регистрации обработчиков, ограничениям параметров.
- Исправлены ошибочные имена макросов в старых комментариях ADS1115, сохранены сами имена символов API.
- MAX31865 документирован как **намеренная заглушка до появления драйвера RT_HW**, без изменения реализации; описаны ограничения `getOk()` в других обёртках.

### Совместимость

Публичные имена классов, методов и параметры не менялись. Версия библиотеки обновлена в `library.properties` до `1.0.1`.
